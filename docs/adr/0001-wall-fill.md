# 墙面净化采用"字面前置"而非三分区合成

**状态**: accepted

渲染新增墙面净化（Wall Fill）：把非岩点区域按 `bg_fill` 强度混向墙面场给出的局部参考色（分块低饱和像素 P90 明度 + 亮部中位数色），抹平脏墙与螺丝孔。关键决策：净化是灰度化的**字面前置**——先改造底图，再走现有保色/灰度合成，而不是让墙面绕过灰度化独立成区（三分区方案）。

选字面前置的理由：不新增掩码通路，渲染合成逻辑零改动；净化效果（均匀亮部）在默认参数下完整可见。已知的反直觉后果：填充色虽然采样了墙面色相，但默认 `bg_sat=0` 下灰度化会丢弃它，墙面呈"局部最浅灰"——色相采样只在 `bg_sat>0` 时显现。这是有意的：两个旋钮正交，`bg_fill` 管干净程度，`bg_sat` 管残留颜色；彩色墙场景调 `bg_sat` 即可覆盖。

## Considered Options

- **三分区合成**（墙面填充为终态、灰度只作用于未选中岩点）：墙面始终保色相，但需要新增"全部岩点掩码"渲染通路，且低强度填充时墙面保留脏污原色、与灰度化的其余画面风格断裂。拒绝。
- **全局单色填充**：实现最简单，但岩馆墙面光照渐变明显，全局单色会在暗部产生拼贴感。拒绝，改用分块墙面场（复用检测回退路径的成熟结构）。
